FPT_Compression UI.lvlib:Graph Cursor Update.vi

Use this VI to update the cursor positions on the selected graphs according to the selected cursor type.

For fixed cursor creation, ensure that its name contains the word ‘fix’.

All default cursors are treated as movable cursors.
