Pulse Measurement Panel.vi

This example demonstrates the configuration of Pulse signal basic properties for measuring the stability properties of a pulse. This example enables traces to view the time domain stability and Pulse to Pulse Stability Traces .

RFmx Settings

    		Center Frequency (Hz)

    Center Frequency (Hz) specifies the expected carrier frequency, in Hz, of the RF signal to acquire. The signal analyzer tunes to this frequency. The default of this property is hardware dependent.

    		Measurement Bandwidth (Hz)

    Measurement Bandwidth specifies the bandwidth of the filter used for the required sample rate. This value is expressed in Hz.

    		Reference Level (dBm)

    Reference Level specifies the reference level which represents the maximum expected power of an RF input signal. This value is configured in dBm for RF devices and as Vpk-pk for baseband devices. The default of this property is hardware dependent.
