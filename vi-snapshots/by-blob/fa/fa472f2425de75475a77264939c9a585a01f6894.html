Power Sequence CSV Validity Check.vi

Validates instrument availability and execution order using extracted CSV data.

If File Path is specified, the VI reads the CSV data from the file. If File Path is empty, the VI uses the data provided through the Extracted CSV input.

Inputs:

- File Path: Path to the extracted CSV file. If empty, Extracted CSV is used.

- Extracted CSV (2D String): CSV data provided directly as a 2D string array.

- error in: Standard error cluster input.

Outputs:

- Instruments not found (1D String): List of instruments that were not found during validation.

- All Instruments Available (Boolean): TRUE if all required instruments are found; otherwise FALSE.

- Valid Execution Order (Boolean): TRUE if the execution order is valid; otherwise FALSE.

- error out: Standard error cluster output.
