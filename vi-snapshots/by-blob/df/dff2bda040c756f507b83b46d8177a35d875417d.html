Results

    		Common Results

      		Frequency (Hz)

      		DUT Noise Figure (dB)

      DUT Noise Figure returns an array of the noise figures of the DUT measured at the frequencies specified by the NF Freq List property. This value is expressed in dB.

      		DUT Noise Temp (K)

      DUT Noise Temperature returns an array of the equivalent thermal noise temperatures of the DUT measured at the frequencies specified by the NF Freq List property. This value is expressed in kelvin.

      		DUT Gain (dB)

      DUT Gain returns an array of the available gains of the DUT measured at the frequencies specified by the NF Freq List property. This value is expressed in dB.

      		Analyzer Noise Figure (dB)

      Analyzer Noise Figure returns an array of the noise figure values of the analyzer measured at the frequencies specified by the NF Freq List property. This value is expressed in dB.

      		Hot Power (dBm)

      Hot Power returns an array of powers measured at the frequencies specified by the NF Freq List property, when the noise source is enabled. This value is expressed in dBm. A valid result is returned only when you set the NF Meas Method property to Y-Factor.

      		Cold Power (dBm)

      Cold Power returns an array of powers measured at the frequencies specified by the NF Freq List property, when the noise source is disabled. This value is expressed in dBm. A valid result is returned only when you set the NF Meas Method property to Y-Factor.

      		Meas Y-Factor (dB)

      Measurement Y-Factor returns the array of measurement Y-Factor values measured at the frequencies specified by the NF Freq List property. This value is expressed in dB. This VI returns a valid result only when you set the NF Meas Method property to Y-Factor.

      		Cal Y-Factor (dB)

      Calibration Y-Factor returns the array of calibration Y-Factor values measured at the frequencies specified by the NF Freq List property. This value is expressed in dB. This VI returns a valid result only when you set the NF Meas Method property to Y-Factor.
