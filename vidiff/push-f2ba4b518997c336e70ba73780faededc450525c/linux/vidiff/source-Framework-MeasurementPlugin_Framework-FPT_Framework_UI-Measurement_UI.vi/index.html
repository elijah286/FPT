SMU Channel[SMU channel]

Specifies the channel(s) to use for the measurement. Specify the channel(s) using the form PXI1Slot3/0,PXI1Slot3/2-3,PXI1Slot4/2-3 or PXI1Slot3/0,PXI1Slot3/2:3,PXI1Slot4/2:3, where PXI1Slot3 and PXI1Slot4 are instrument resource names and 0, 2, and 3 are channels. If you do not wire this parameter, LabVIEW uses all channels in the instrument session for the measurement.
