RFSG Pulsed Data.vi

Demonstrates how to use scripts to generate pulsed data. Pulsed data is typically used in time division multiplexing (TDM) systems. TDM is a type of multiplexing where two or more channels of information are transmitted over the same link by allocating a different time interval ("slot") for the transmission of each channel. The set of all slots makes up a frame. This example generates a CW inside one of the time slots.
